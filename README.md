Company Project (Spring Boot Backend)
📌 Overview

This project is a backend system built with Spring Boot.
It provides a foundation for managing company data such as users and related entities.
The project follows clean backend development practices, making use of DTOs, Projections, Pagination, JPA, and Microservices architecture.

🚀 Features

User Management – Create, read, update, and delete company users.

Pagination – Efficient handling of large datasets with pageable endpoints.

DTOs (Data Transfer Objects) – Clean separation between entities and exposed API data.

Projections – Optimized queries returning only required fields.

JPA / Hibernate – Simplified database interaction with MySQL.

Microservices-ready – Structured in a way that supports modular service separation.

🛠️ Technologies Used

Java 17+

Spring Boot

Spring Data JPA

MySQL

Maven/Gradle

Lombok
